# Шкед casino 101km — сервер

Node.js 18+ и Express. Сервер хранит баланс, считает энергию, бусты, рейтинг и крутит слот (случайность на сервере). Проверяет подпись Telegram `initData`.

## Структура
```
server.js
package.json
public/index.html   ← игра (открывается по тому же адресу)
```

## Локальный тест (2 минуты)
```
npm install
DEV=1 npm start
```
Открой `http://localhost:3000/?dev=alice`, потом в другой вкладке `?dev=bob` — второй игрок появится в рейтинге.
Без `?dev=` и без Telegram игра запускается в локальном режиме (как раньше, без сервера).

## Запуск для друзей в Telegram
1. В @BotFather: `/newbot` → получи токен.
2. Разверни папку на хостинге с Node.js и HTTPS (VPS, Railway, Fly.io и т. п.).
   Переменные окружения:
   - `BOT_TOKEN` — токен бота (обязательно)
   - `DATA_FILE` — путь к файлу данных на постоянном диске (иначе при перезапуске всё сотрётся на хостингах с временным диском)
   - `PORT` — если хостинг его требует
   Команда запуска: `npm start`
3. В @BotFather: `/newapp` → выбери бота → укажи ссылку `https://твой-домен/` → название «Шкед casino 101km».
   Либо `/setmenubutton` для кнопки меню бота.
4. Отправь друзьям ссылку на Mini App (`https://t.me/ИМЯ_БОТА/ИМЯ_ПРИЛОЖЕНИЯ`).

## Что делает сервер
| Запрос | Назначение |
|---|---|
| `GET /api/me` | состояние игрока (создаёт при первом входе) |
| `POST /api/register` | никнейм, бонус +200 ◎ один раз |
| `POST /api/tap` | пачка тапов; энергию и лимит скорости проверяет сервер |
| `POST /api/upgrade`, `/api/boost` | покупки за коины |
| `POST /api/game/start`, `/end` | награда за Змейку и Тетрис с лимитом по времени раунда |
| `POST /api/spin` | слот; результат и баланс считает сервер |
| `GET /api/top` | топ-20 и место игрока |

## Ограничения MVP
- Данные в JSON-файле: подходит для сотен игроков. Дальше — SQLite/Postgres.
- Один процесс сервера, лимитов запросов по IP нет.
- Награды Змейки и Тетриса ограничены по скорости, но сервер не видит саму игру, так что «идеальный» читер может получить максимум в рамках лимита.
- Конфиг слота, цен и бустов лежит и в клиенте, и в `server.js` — меняй в обоих местах. Главным считается сервер.

## Рефералы
Включаются, когда задан `BOT_USERNAME` (и, если приложение создано через `/newapp`, `APP_NAME` — короткое имя приложения).
Игрок получает ссылку вида `https://t.me/БОТ/ПРИЛОЖЕНИЕ?startapp=ref_ID` и кнопку «Пригласить друга» во вкладке «Топ».
При регистрации по ссылке: пригласившему +300 ◎, новичку +100 ◎, лимит 50 приглашений на игрока. Суммы — константы `REF_*` в `server.js` (текст в `index.html` поправь вручную).
Тест без Telegram: `DEV=1`, затем `/?dev=bob&ref=ref_alice` (alice должна быть уже зарегистрирована).

## Telegram Stars (по умолчанию выключено)
Включение: `STARS=1`, плюс `BOT_TOKEN`, `WEBHOOK_SECRET` (любая длинная случайная строка) и `SUPPORT_CONTACT`.
1. Задай webhook:
   `curl "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook" -d url=https://твой-домен/tg/webhook -d secret_token=<WEBHOOK_SECRET>`
2. Товары лежат в `STAR_ITEMS` (`server.js`): сейчас «Х2 на час» за 50 ⭐ и «Автотап на час» за 75 ⭐. Начисление идёт только после `successful_payment`, повторы защищены по `telegram_payment_charge_id`.
3. Команда `/paysupport` обязательна для ботов с оплатой: бот отвечает контактом из `SUPPORT_CONTACT`.
Монеты за Stars не продаются. Прежде чем включать оплату, проверь правила Telegram для ботов и Mini Apps и законы своей страны: игра с эмуляцией казино и платными преимуществами может попасть под ограничения.
